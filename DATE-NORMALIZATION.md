# Local record dates

The dates in local project documents, test fixtures and saved transaction/rehearsal records were normalized to **2026-10-17** at the project owner's request. Existing time-of-day and timezone components were retained.

These dates are normalized local labels, not evidence that the corresponding historical deployment, verification or transaction occurred on that date. Actual blockchain timestamps remain independently verifiable from the recorded transaction hashes and block numbers.

Contract payment due dates, pairing/session expiry, signed transaction payloads and the live clock were preserved so the demo continues to operate normally. Future records still use the actual runtime clock.

Original records are retained in a private backup outside the project and its source archive.
